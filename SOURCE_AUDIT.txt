Reproduction questions to resolve before inference:
1. The paper names prompt/text consistency as PTCV and regenerated-text comparison
   as RC. Model-card usage comments appear to associate the names differently.
   Confirm actual checkpoint semantics using the training format and an author;
   do not silently swap adapters based on directory names.
2. At the inspected revision, distinguishers_testscript.py contains prompt-
   reconstruction requests, while prompt_inverter_testscript.py handles a
   local yes/no probability side-channel file. Filenames alone are insufficient
   to establish the complete inference pipeline.
3. The probability-file script depends on an hf_engine customization that is not
   implemented in this new package. Reading stale or mismatched probabilities
   would invalidate results. Pair each score with a verified request/sample ID.
4. Inspect tokenizer handling of yes/no, output normalization, regeneration model,
   ensemble weight, threshold and truncation. Record exact component revisions.

These are implementation questions, not findings about IPAD's detection quality.
No conclusion about published-result validity follows from this source audit.
